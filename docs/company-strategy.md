# Meridian company strategy: source context

[Canonical Confluence strategy](https://beacon-stone.atlassian.net/wiki/spaces/SPT/pages/148209689) is the existing authoritative demo document. The earlier repository seed has been superseded by this source reference.

Meridian is a fictional digital-first bank headquartered in New York with approximately 4M UK/US customers. The source strategy targets European expansion and triple digital payment volume by FY28 against the **FY25 exit run rate**, not FY26. It describes Adyen as primary acquiring and Worldpay as failover/legacy, with no European provider contracted in the story.

The platform ambition includes consistent provider contracts, market/cost/health-aware routing and eventual mobile configuration without app-store releases. Mobile's current baseline is intentionally hardcoded to two providers. The future integration remains unresolved.

See [workspace map](workspace-map.md), [provider playbook](provider-expansion-playbook.md), [policy](compliance-policy.md) and [API standards](api-standards.md). Implementation scope is a synthetic connected rehearsal, not a representation of production readiness or actual provider market coverage.
