## Whiteboard

Child page: [Whiteboard](whiteboard.md).

The module is a 20-minute demo script. It covers three beats, in this order:

1. Import from Miro, so stickies stay editable.
2. Sticky-to-Jira conversion.
3. Rovo summarise, using **Summarize what I'm looking at**.

Rovo grouping is a short beat inside the same Rovo section. It is the other displacement move named on WHIT-14. Recording the demo as a Loom is out of scope until this script is approved. Certification is the single Whiteboard item on the [Q3 2026 Sales Enablement Hub](../q3-2026-sales-enablement-hub.md) checklist.

## What this seed does not do

It does not replace the rest of v2026.04, change the 60-day ramp target, or publish the page to Confluence. Product steps cite public Atlassian Support, linked from the module page.
