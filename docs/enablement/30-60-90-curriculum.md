# 30/60/90 curriculum

From the Q3 Planning Offsite. Confluence-ready seed for [WHIT-14](https://beacon-stone.atlassian.net/browse/WHIT-14). Not a published Confluence page.

The offsite curriculum and the [New Rep Onboarding Playbook v2026.04](new-rep-onboarding-playbook-v2026.04/index.md) were ramping reps in 78 days against a 60-day target, and neither mentioned Whiteboard. This page places that module in the first 30 days. Other offsite modules were not in this workspace, so they are not rewritten here. Days 31–60 and 61–90 are unchanged by WHIT-14.

Ramp target stays 60 days. Adding Whiteboard early is what keeps that target flat. It does not add a new week.

## Days 1–30

Checkpoint: the rep can run the displacement demo without a manager driving the mouse.

| Module | Time | Page | Done when |
| --- | --- | --- | --- |
| Whiteboard | 20-minute live demo, plus one unassisted practice on a second synthetic board | [Whiteboard](new-rep-onboarding-playbook-v2026.04/whiteboard.md) | Imported a Miro Vector PDF so stickies stayed editable, converted selected stickies to Jira work items, and used Rovo **Summarize what I'm looking at** to create or copy a summary |

Schedule the coached 20 minutes in week one, and the unassisted run before the day-30 checkpoint. The practice board uses different sticky text from the Harborline script. Links to bring to the checkpoint: the imported whiteboard, one created work item, and the summary page.

Rovo grouping is practiced inside that same session. It is not a separate module. A Loom recording is not required in the first 30 days.

Certification for this row is the one Whiteboard item on the [Q3 2026 Sales Enablement Hub](q3-2026-sales-enablement-hub.md) checklist. Do not mark the day-30 checkpoint complete if Rovo was unavailable and the summary was skipped.

## Days 31–60

No Whiteboard module is added here. The rep uses the day-30 demo on a live discovery call only after the checklist item is signed. Deal-specific boards still stay synthetic until the prospect exports their own file and a named Jira space is agreed. That conversation is not a second curriculum module.

## Days 61–90

No Whiteboard module is added here. Bulk Miro import (Spaces, Import from other tools, Miro) is a solution-consultant motion for a later expansion, not a day-61 rep module. The first-30 script already tells the rep how to describe that path without running it.
